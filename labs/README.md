## How each write-up is structured

1. **Overview** — what the lab/room is and where it sits in the learning path
2. **What I learned** — concepts and skills, in plain language
3. **Key commands / techniques** — the tools and methods practised
4. **Why it matters** — how it applies to a SOC Analyst / penetration tester role
5. **What is next** — the follow-on lab or topic

## Scope and ethics

- All labs were completed on purpose-built training platforms
  (TryHackMe, PortSwigger Web Security Academy) that exist for this exact
  purpose.
- Testing is done only on systems I own or have explicit permission to test.
  Nothing here targets real websites, real organisations, or real users.
- Bug bounty work is done only inside an authorised scope, following the
  program's rules and responsible disclosure.

## Learning path

Foundations (Linux, networking) → Web application security (SQLi, XSS,
authentication, access control) → Penetration testing methodology →
SOC / blue-team skills → Bug bounty (authorised scope only).
