## Practical Explanation

- **Why PE2 matters for cyber security:** PE1 taught the language; PE2 teaches the engineering — modules and packages for organising tooling, OOP for building reusable security tools, exceptions for scripts that fail safely, and file processing for log analysis. A SOC analyst's daily work (parsing logs, automating triage, calling APIs) is built from exactly these pieces.
- **Module 3 at 100%:** object-oriented thinking is what turns one-off scripts into tools other people can use — classes for a scanner, objects for a finding, inheritance for a family of checks.
- **The Final Exam (93%):** 40 questions across the whole course at a 70% pass mark — the score confirms the material stuck, not just the module tests.
