- **Why Python matters for cyber security:** Python is the scripting language of security work — automation, log parsing, API calls, exploit tooling and SOC scripting all run on it. The control-flow and data-structure skills from this course (loops, lists, dictionaries, exceptions) are exactly what security scripts are built from.
- **Retaking Module 4's test (95% → 100%):** a wrong answer is a gap, not a grade. Re-reading the question and re-attempting until every answer is correct is the same habit as re-testing a vulnerability after a fix.
- **The Final Project (Digit of Life):** a complete program from scratch — reading input, validating it, looping over digits and producing a result. That is the whole workflow: input → processing → output, with error handling.
